    How it works

    1. Add your files

    Drop a ZIP, a folder, or loose files. The page that opens first must be named index.html.

    2. Name your app

    Type a name and, if you like, pick an icon. Everything else has a sensible default.

    3. Install it

    Download the APK, open it on your Android phone, and allow installs from this source when asked.

    Good to know

    • Works like your siteYour pages run inside Android's built-in web view and are stored in the app, so they open without internet. Links to other websites open in the browser.
    • Local files and modulesScripts, styles, images and fonts load normally. Reading your own files with fetch() and ES modules (type="module") do not work on local pages, so use regular script tags.
    • One key for updatesAPKs are signed with a key saved in this browser. Build from the same browser, or download the key, to update an app you installed earlier.
    • For direct sharingShare the APK yourself. App stores may not accept it, and Android can show a warning for apps from outside the store.
